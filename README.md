# Курс по гляциологии

Учебный курс, интегрирующий теоретическую физику льда с численным моделированием

## Структура

- **module2_glen_law/** — Лекция 2: Реология льда и закон Глена
  - Реализация закона Глена (ε̇ = A·τⁿ)
  - Уравнение Аррениуса для коэффициента мягкости A(T)
  - Расчёт эффективной вязкости льда (в т.ч. с поправкой на содержание пыли)
  - Модель отклика льда на циклическую нагрузку (упругая + вязкая деформация)

- **module3_sia_ssa/** — Лекция 3: Численное моделирование течения льда (SIA и SSA)
  - SIA: неявная (устойчивая) конечно-разностная схема эволюции толщины ледника
  - SSA: аналитическое решение Веертмана для шельфа, самосогласованное с неразрывностью
  - Упрощённый закон базального скольжения (Weertman), откалиброванный по
    реальным наблюдениям ITS_LIVE (NASA JPL) — без него SIA-модель занижает
    скорости выводных ледников в разы, так как учитывает только внутреннюю
    деформацию льда без скольжения по ложу

- **module4_zoet_iverson/** — Модуль 4: Механика скольжения и закон Зоэта-Иверсона
  - Регуляризованный закон Кулона (Zoet & Iverson, 2020): универсальный
    закон скольжения, объединяющий степенной и кулоновский режимы
  - Параметризация переходной скорости u_t от размера обломков и
    эффективного давления N
  - Пружинно-ползунковая модель stick-slip: показано, что закон устойчив
    при постоянном N, а реальные "прыжки" (как на Whillans Ice Stream)
    возникают из-за приливной модуляции эффективного давления
