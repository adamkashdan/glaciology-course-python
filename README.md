# Курс по гляциологии

Учебный курс, интегрирующий теоретическую физику льда с численным моделированием

## Структура

- **module2_glen_law/** — Лекция 2: Реология льда и закон Глена
  - Реализация закона Глена (ε̇ = A·τⁿ)
  - Уравнение Аррениуса для коэффициента мягкости A(T)
  - Расчёт эффективной вязкости льда (в т.ч. с поправкой на содержание пыли)
  - Модель отклика льда на циклическую нагрузку (упругая + вязкая деформация)

## Установка

```bash
pip install numpy matplotlib scipy
```

## Запуск

```bash
cd module2_glen_law
python module2_glen_law.py
```

Графики сохраняются в `module2_glen_law/outputs/`.

## Планируемые модули

1. Анализ данных и простые климатические модели
2. **Реология льда и закон Глена** ✅
3. Численное моделирование течения (SIA и SSA)
4. Механика скольжения и закон Зоэта-Иверсона
5. Стабильность морских ледниковых щитов
6. Прогнозирование уровня моря
